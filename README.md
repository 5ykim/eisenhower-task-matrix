# 할일 아이젠하워 매트릭스

할 일을 아이젠하워 매트릭스의 네 영역으로 분류하는 정적 웹 앱입니다.

## 사용한 수업 개념

- **함수**: `classifyTask`, `addTask`, `renderTasks` 등으로 역할을 나눴습니다.
- **조건문**: 중요·긴급 여부에 따라 할 일을 네 영역으로 분류합니다.
- **반복문**: `for ... of`로 등록한 모든 할 일을 화면에 표시합니다.
- **리스트와 딕셔너리**: 할 일 목록은 배열에, 각 할 일의 정보는 객체에 저장합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 API 키가 필요하지 않습니다.

## 제출 정보

- 작품명: 할일 아이젠하워 매트릭스
- 과제 구분: 과제 1
- 한줄 소개: 사용자가 입력한 할 일을 중요도와 긴급도에 따라 네 가지 우선순위로 분류하는 개인 할 일 정리 앱입니다.
- 데이터 출처: 사용자 직접 입력(외부 데이터 미사용)
